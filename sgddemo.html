1 问题：为什么需要 200 次实验？

我们有一个线性回归模型：

\[ \hat{y} = \beta_0 + \beta_1 x \]

模型有两个未知参数 \(\beta_0, \beta_1\)，理论上只需要两次实验就能精确求解。

但现实中，实验数据总带有噪声。两次实验的结果可能偏差很大，直接求解毫无意义。

策略转变：既然单次实验不可靠，那就做 200 次（甚至更多），然后用最小二乘法找到一组”最优”的参数。

这就引出了两个核心问题：

  1. “最优”的数学含义是什么？（→ 最小二乘 → 超定方程 → 正规方程）
  2. 除了直接求解，还有没有其他方式逼近最优解？（→ 梯度下降 → SGD）

2 正规方程（Normal Equation）

2.1 从模型到超定方程

将模型写成矩阵形式。设计矩阵 \(X\) 和参数向量 \(\boldsymbol{\beta}\)：

\[ X = \begin{pmatrix} 1 & x_1 \\ 1 & x_2 \\ \vdots & \vdots \\ 1 & x_n \end{pmatrix}_{n \times 2}, \quad \boldsymbol{\beta} = \begin{pmatrix} \beta_0 \\ \beta_1 \end{pmatrix} \]

理想情况下，我们希望：

\[ \mathbf{y} = X\boldsymbol{\beta} \]

但这里有 \(n = 200\) 个方程、只有 2 个未知数——这是一个超定方程（overdetermined system）。

Note超定方程的几何直觉

超定方程的关键性质：

  • 没有精确解：方程数远多于未知数，不可能同时满足所有方程。
  • \(X\boldsymbol{\beta}\) 是 \(X\) 的列空间中的向量：无论 \(\boldsymbol{\beta}\) 取什么值，\(X\boldsymbol{\beta}\) 只能是 \(X\) 的列向量的线性组合。
  • \(\mathbf{y}\) 不在列空间里：因为有噪声，真实的 \(\mathbf{y}\) 落在了列空间之外。
  • 最优解 = 投影：我们要找 \(\boldsymbol{\beta}^*\) 使得 \(X\boldsymbol{\beta}^*\) 是 \(\mathbf{y}\) 在 \(X\) 列空间上的正交投影，即距离最近的点。

2.2 最小二乘推导

定义残差向量 \(\mathbf{r} = \mathbf{y} - X\boldsymbol{\beta}^*\)，我们要最小化残差的欧几里得范数平方：

\[ \min_{\boldsymbol{\beta}} \| X\boldsymbol{\beta} - \mathbf{y} \|^2 \]

由投影的几何性质，最优解处残差向量垂直于 \(X\) 的列空间，即残差与 \(X\) 的每一列正交：

\[ X^T \mathbf{r} = \mathbf{0} \]

展开：

\[ X^T(\mathbf{y} - X\boldsymbol{\beta}^*) = \mathbf{0} \]

\[ X^T X \boldsymbol{\beta}^* = X^T \mathbf{y} \]

这就是正规方程（Normal Equation）。当 \(X^T X\) 可逆时，直接求解：

\[ \boxed{\boldsymbol{\beta}^* = (X^T X)^{-1} X^T \mathbf{y}} \]

3 随机梯度下降（SGD）

正规方程是一步到位的解析解。但当数据量巨大（百万级）或 \(X^TX\) 不好求逆时，我们需要另一条路：迭代逼近。

3.1 损失函数与梯度

对于一个大小为 \(m\) 的 mini-batch，损失函数为均方误差：

\[ L(\boldsymbol{\beta}) = \frac{1}{m} (\mathbf{y} - X\boldsymbol{\beta})^T (\mathbf{y} - X\boldsymbol{\beta}) \]

展开这个二次型：

\[ L = \frac{1}{m} \left( \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\beta}^T X^T \mathbf{y} + \boldsymbol{\beta}^T X^T X \boldsymbol{\beta} \right) \]

Note用到的矩阵求导公式

  • \(\dfrac{\partial}{\partial \boldsymbol{\beta}} (\boldsymbol{\beta}^T \mathbf{a}) = \mathbf{a}\)

  • \(\dfrac{\partial}{\partial \boldsymbol{\beta}} (\boldsymbol{\beta}^T A \boldsymbol{\beta}) = 2A\boldsymbol{\beta}\)（\(A\) 为对称矩阵）

对 \(\boldsymbol{\beta}\) 求导：

\[ \frac{\partial L}{\partial \boldsymbol{\beta}} = \frac{1}{m} \left( 0 - 2X^T\mathbf{y} + 2X^TX\boldsymbol{\beta} \right) = \frac{-2}{m} X^T (\mathbf{y} - X\boldsymbol{\beta}) \]

\[ \boxed{\nabla_{\boldsymbol{\beta}} L = \frac{-2}{m} X^T (\mathbf{y} - X\boldsymbol{\beta})} \]

3.2 更新规则

每一步迭代：

\[ \boldsymbol{\beta}^{(t+1)} = \boldsymbol{\beta}^{(t)} - \eta \cdot \nabla_{\boldsymbol{\beta}} L \]

其中 \(\eta\) 是学习率。

Important注意梯度方向

梯度 \(\nabla L\) 的负号意味着：当预测值偏小（\(\mathbf{y} - X\boldsymbol{\beta} > 0\)）时，梯度为负，减去负值等于增大 \(\boldsymbol{\beta}\)，参数向正确方向调整。

3.3 SGD 的完整流程

初始化 β = (0, 0)，设学习率 η，批量大小 m

重复 n_epochs 轮：
    打乱全部数据
    每次取 m 条数据作为一个 mini-batch：
        1. 计算残差: r = y_batch - X_batch %*% β
        2. 计算梯度: g = -2/m * X_batch' %*% r
        3. 更新参数: β = β - η * g

3.4 R 代码实现

查看代码 | Code anzeigen 
# ----- Mini-batch SGD 求解 -----
learning_rate <- 0.005
batch_size <- 16
n_epochs <- 200

beta_sgd <- c(0, 0)
loss_history <- numeric(n_epochs)
beta_history <- matrix(NA, nrow = n_epochs, ncol = 2)

for (epoch in 1:n_epochs) {
  # 每个 epoch 打乱数据顺序
  idx <- sample(1:n)
  X_shuffled <- X[idx, ]
  y_shuffled <- y[idx]

  for (i in seq(1, n, batch_size)) {
    # 取一个 mini-batch
    batch_end <- min(i + batch_size - 1, n)
    batch_idx <- i:batch_end
    X_batch <- X_shuffled[batch_idx, , drop = FALSE]
    y_batch <- y_shuffled[batch_idx]
    m <- length(batch_idx)

    # 梯度: -2/m * X'(y - Xβ)
    residuals <- y_batch - X_batch %*% beta_sgd
    gradient <- -2 / m * t(X_batch) %*% residuals

    # 参数更新
    beta_sgd <- beta_sgd - learning_rate * gradient
  }

  # 记录每个 epoch 结束时的状态
  loss_history[epoch] <- mean((y - X %*% beta_sgd)^2)
  beta_history[epoch, ] <- beta_sgd
}

Note正规方程 vs SGD：什么时候用哪个？

正规方程的优势在于精确、无需调参、一步到位。但它需要计算 \(X^TX\) 的逆（或等价的分解），当特征数 \(p\) 很大时，\((p \times p)\) 矩阵求逆的计算量为 \(O(p^3)\)，内存占用为 \(O(p^2)\)，会成为瓶颈。

SGD 的优势在于可扩展性：每一步只看一小批数据，内存开销小，天然适合大规模数据和在线学习场景。代价是需要调节学习率、批量大小、轮数等超参数，而且只能逼近而非精确达到最优解。

简单来说：数据小、特征少 → 正规方程；数据大、特征多、或需要在线更新 → SGD。

5 扩展：从线性到真正的非线性

上面我们用正规方程和 SGD 两条路求解了线性回归。一个自然的想法是：如果模型不是直线，比如加个平方项，是不是正规方程就用不了了？

5.1 常见误区：多项式回归仍然是”线性”模型

考虑模型：

\[ \hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2 \]

虽然对 \(x\) 来说是二次曲线，但对参数 \(\beta_0, \beta_1, \beta_2\) 来说仍然是线性的。

只需令 \(z_1 = x,\; z_2 = x^2\)，设计矩阵变成：

\[ X = \begin{pmatrix} 1 & x_1 & x_1^2 \\ 1 & x_2 & x_2^2 \\ \vdots & \vdots & \vdots \end{pmatrix}_{n \times 3}, \quad \boldsymbol{\beta} = \begin{pmatrix} \beta_0 \\ \beta_1 \\ \beta_2 \end{pmatrix} \]

模型仍然是 \(y = X\beta\)，正规方程 \(\beta^* = (X^TX)^{-1}X^Ty\) 照常使用。

Important「线性回归」中的「线性」指的是什么？

指的是对参数线性，不是对 \(x\) 线性。只要模型能写成 \(y = X\beta\)（参数的线性组合），无论 \(x\) 做了什么变换（平方、取对数、交叉项……），都属于线性模型，正规方程都能用。这是一个非常常见的混淆点——“加了平方项就不是线性模型了”，其实不然。

5.2 真正的非线性模型：饱和曲线

那什么情况下正规方程彻底失效？当参数出现在非线性位置时。

考虑一个在酶动力学、药物吸收、学习曲线中非常常见的饱和模型（Michaelis-Menten 方程）：

\[ \hat{y} = \frac{\beta_0 \, x}{\beta_1 + x} \]

其中 \(\beta_0\) 是饱和值（当 \(x \to \infty\) 时 \(\hat{y}\) 趋近的最大值），\(\beta_1\) 是半饱和常数（\(\hat{y}\) 达到 \(\beta_0 / 2\) 时对应的 \(x\) 值）。

为什么这是真正的非线性？ \(\beta_1\) 出现在分母中，与 \(x\) 相加。无论怎么做变量替换，都不可能把这个模型写成 \(y = X\beta\) 的矩阵乘法形式。

Note为什么选择饱和曲线而不是指数模型？

另一个常见的非线性模型是指数增长 \(y = \beta_0 e^{\beta_1 x}\)。我们没有使用它，因为指数函数在 SGD 中容易数值爆炸——\(\beta_1\) 稍微偏大，梯度就会呈指数级增长，导致发散。饱和曲线模型的梯度天然有界（分母的平方保证了这一点），用普通 SGD 就能稳定收敛，更适合教学演示。

5.3 为什么正规方程失效

回忆线性模型中正规方程的推导逻辑：

\[ \text{模型: } \hat{y} = X\beta \quad\Longrightarrow\quad \text{梯度: } -\frac{2}{m}X^T(y - X\beta) = 0 \quad\Longrightarrow\quad X^TX\beta = X^Ty \]

最后一步是关于 \(\beta\) 的线性方程，所以能直接解。

对于非线性模型 \(\hat{y}_i = f(x_i; \beta)\)：

\[ \text{梯度: } \frac{\partial L}{\partial \beta_j} = -\frac{2}{m}\sum_{i=1}^{m}(y_i - f(x_i;\beta)) \cdot \frac{\partial f}{\partial \beta_j} = 0 \]

令梯度为零后得到的方程是非线性的——因为 \(f\) 和 \(\frac{\partial f}{\partial \beta_j}\) 本身都依赖 \(\beta\)。没有办法像正规方程那样一步解出 \(\beta^*\)。

Note直觉理解

在线性模型中，损失函数 \(L(\beta)\) 是 \(\beta\) 的二次函数（碗状曲面），碗只有一个最低点，设导数为零就能找到它。

在非线性模型中，损失函数的形状复杂得多，可能有多个山谷和鞍点，没有公式能直接跳到最低点，只能从某个起始位置出发，沿着下降方向一步步走——这正是 SGD 做的事。

结论：只能靠迭代优化（如 SGD）逐步逼近。

5.4 用链式法则推导梯度

损失函数仍然是均方误差，但预测值不再是简单的矩阵乘法：

\[ L(\beta) = \frac{1}{m}\sum_{i=1}^{m}\left(y_i - \frac{\beta_0 x_i}{\beta_1 + x_i}\right)^2 \]

用链式法则对每个参数求偏导：

\[ \frac{\partial L}{\partial \beta_j} = \frac{-2}{m}\sum_{i=1}^{m}\underbrace{(y_i - \hat{y}_i)}_{\text{残差 } r_i} \cdot \underbrace{\frac{\partial f}{\partial \beta_j}}_{\text{模型对参数的偏导}} \]

分别计算模型函数 \(f = \frac{\beta_0 x}{\beta_1 + x}\) 对两个参数的偏导：

\[ \frac{\partial f}{\partial \beta_0} = \frac{x}{\beta_1 + x} \]

\[ \frac{\partial f}{\partial \beta_1} = -\frac{\beta_0 x}{(\beta_1 + x)^2} \]

（第二个使用了商法则：分子 \(\beta_0 x\) 对 \(\beta_1\) 的导数为 0，分母 \(\beta_1 + x\) 对 \(\beta_1\) 的导数为 1）

所以完整的梯度为：

\[ \frac{\partial L}{\partial \beta_0} = \frac{-2}{m}\sum_{i=1}^{m} r_i \cdot \frac{x_i}{\beta_1 + x_i} \]

\[ \frac{\partial L}{\partial \beta_1} = \frac{-2}{m}\sum_{i=1}^{m} r_i \cdot \left(-\frac{\beta_0 x_i}{(\beta_1 + x_i)^2}\right) = \frac{2}{m}\sum_{i=1}^{m} r_i \cdot \frac{\beta_0 x_i}{(\beta_1 + x_i)^2} \]

Tip对比线性模型的梯度

线性模型的梯度是 \(-\frac{2}{m}X^T(y - X\beta)\)，其中 \(X\) 是固定的设计矩阵，不依赖 \(\beta\)。

非线性模型的梯度中，“等效的 \(X\)”（即偏导数矩阵）随 \(\beta\) 变化。这意味着每走一步，梯度的计算方式都在变，正是这一点让问题无法用一个线性方程一步解决。

# ===== 3. SGD 求解非线性模型 =====
learning_rate_nl <- 0.02
batch_size_nl <- 16
n_epochs_nl <- 300

beta_nl <- c(5, 5)   # 初始猜测（远离真值）
loss_history_nl <- numeric(n_epochs_nl)
beta_history_nl <- matrix(NA, nrow = n_epochs_nl, ncol = 2)

for (epoch in 1:n_epochs_nl) {
  # 打乱数据
  idx <- sample(1:n)
  x_shuf <- x_nl[idx]
  y_shuf <- y_nl[idx]

  for (i in seq(1, n, batch_size_nl)) {
    # 取 mini-batch
    batch_end <- min(i + batch_size_nl - 1, n)
    bi <- i:batch_end
    xb <- x_shuf[bi]
    yb <- y_shuf[bi]
    m  <- length(bi)

    # --- 前向传播：计算预测值 ---
    y_hat <- beta_nl[1] * xb / (beta_nl[2] + xb)

    # --- 计算残差 ---
    r <- yb - y_hat

    # --- 模型对参数的偏导数 ---
    df_db0 <- xb / (beta_nl[2] + xb)                       # ∂f/∂β0
    df_db1 <- -beta_nl[1] * xb / (beta_nl[2] + xb)^2      # ∂f/∂β1

    # --- 损失函数的梯度 ---
    grad <- c(
      -2 / m * sum(r * df_db0),    # ∂L/∂β0
      -2 / m * sum(r * df_db1)     # ∂L/∂β1
    )

    # --- 参数更新 ---
    beta_nl <- beta_nl - learning_rate_nl * grad
  }

  # 记录每个 epoch 结束时的状态
  y_pred_all <- beta_nl[1] * x_nl / (beta_nl[2] + x_nl)
  loss_history_nl[epoch] <- mean((y_nl - y_pred_all)^2)
  beta_history_nl[epoch, ] <- beta_nl
}

mse_nl <- loss_history_nl[n_epochs_nl]

5.8 SGD 实践：学习率与初始值的影响

上一节中我们用学习率 0.02、初始值 (5, 5) 成功拟合了饱和曲线。但这两个数字是怎么选的？选错了会怎样？

在线性模型中（§3），这个问题不太重要：损失函数 \(L(\beta)\) 是 \(\beta\) 的二次函数——一个完美的碗，只有唯一的最低点。SGD 从哪里出发、步子多大，只要不太离谱，最终都会收敛到正规方程给出的同一个解。

非线性模型的损失曲面没这么友好。下面通过实验体会这一点。

5.8.1 先看地形：损失曲面

在改变超参数之前，先把损失函数 \(L(\beta_0, \beta_1)\) 的”地形图”画出来，建立直觉。

几个观察：

  1. 等高线呈椭圆形而非正圆——说明两个参数方向上的曲率不同（\(\beta_0\) 方向更平坦）
  2. 只有一个谷底（在真实值附近）——这个特定模型的损失曲面是”类凸”的，不存在局部极小
  3. 等高线的间距不均匀——离谷底越远梯度越陡，越近梯度越缓
Note并非所有非线性模型都这么友好

饱和曲线只有 2 个参数且函数形式简单，损失曲面接近凸形。如果模型更复杂（比如神经网络有几千个参数），损失曲面会出现大量鞍点和局部极小，初始值的选择就变得至关重要。但即使在这个简单模型上，超参数的影响已经清晰可见。

5.8.2 学习率对比

学习率（learning rate, \(\eta\)）控制每一步沿梯度方向走多远：

\[ \beta^{(t+1)} = \beta^{(t)} - \eta \cdot \nabla L \]

直觉上：\(\eta\) 太小，每步挪动微乎其微，需要极多轮次才能到达谷底；\(\eta\) 太大，步子迈过了谷底，在两侧来回弹跳。我们用三个学习率（0.001, 0.02, 0.1）跑同一个模型，初始值统一为 (5, 5)：

查看代码 | Code anzeigen 
set.seed(2024)

lrs <- c(0.001, 0.02, 0.1)
lr_cols <- c("#3498db", "#2ecc71", "#e74c3c")

n_ep_lr <- 300
bs_lr <- 16

loss_by_lr <- matrix(NA, n_ep_lr, 3)
path_by_lr <- vector("list", 3)

for (k in 1:3) {
  beta <- c(5, 5)
  path <- matrix(NA, n_ep_lr, 2)

  for (ep in 1:n_ep_lr) {
    idx <- sample(1:n)
    xs <- x_nl[idx]; ys <- y_nl[idx]

    for (i in seq(1, n, bs_lr)) {
      bi <- i:min(i + bs_lr - 1, n)
      xb <- xs[bi]; yb <- ys[bi]; m <- length(bi)

      denom <- beta[2] + xb
      y_hat <- beta[1] * xb / denom
      r <- yb - y_hat

      g <- c(
        -2 / m * sum(r * xb / denom),
         2 / m * sum(r * beta[1] * xb / denom^2)
      )

      # 梯度裁剪：防止偏大学习率导致数值爆炸
      gn <- sqrt(sum(g^2))
      if (gn > 100) g <- g * (100 / gn)

      beta <- beta - lrs[k] * g
    }

    y_all <- beta[1] * x_nl / (beta[2] + x_nl)
    loss_by_lr[ep, k] <- mean((y_nl - y_all)^2)
    path[ep, ] <- beta
  }

  path_by_lr[[k]] <- path
}

  • lr = 0.02（绿）：损失快速下降并稳定在理论下界 \(\sigma^2 = 0.25\) 附近。轨迹干净利落地走向谷底。拟合曲线与真实曲线几乎重合。
  • lr = 0.1（红）：前几步下降很快，但之后在谷底附近震荡——步子太大，越过了最低点又弹回来。损失曲线呈锯齿状，最终的 MSE 可能略高于 lr = 0.02 的结果。
Tip学习率选择的矛盾

大学习率收敛快但震荡，小学习率平稳但太慢。一个常见的折中策略是学习率衰减（learning rate decay）：开始时用较大的学习率快速接近谷底，然后逐渐减小以精确定位最低点。例如 \(\eta_t = \eta_0 / (1 + \alpha \cdot t)\)，其中 \(\alpha\) 控制衰减速度。

loss_by_init <- matrix(NA, n_ep_init, 4)

for (k in 1:4) {
  beta <- starts[[k]]
  path <- matrix(NA, n_ep_init, 2)

  for (ep in 1:n_ep_init) {
    idx <- sample(1:n)
    xs <- x_nl[idx]; ys <- y_nl[idx]

    for (i in seq(1, n, bs_lr)) {
      bi <- i:min(i + bs_lr - 1, n)
      xb <- xs[bi]; yb <- ys[bi]; m <- length(bi)

      denom <- beta[2] + xb
      y_hat <- beta[1] * xb / denom
      r <- yb - y_hat

      g <- c(
        -2 / m * sum(r * xb / denom),
         2 / m * sum(r * beta[1] * xb / denom^2)
      )

      gn <- sqrt(sum(g^2))
      if (gn > 100) g <- g * (100 / gn)

      beta <- beta - lr_init * g
    }

    y_all <- beta[1] * x_nl / (beta[2] + x_nl)
    loss_by_init[ep, k] <- mean((y_nl - y_all)^2)
    path[ep, ] <- beta
  }

  path_by_init[[k]] <- path
}

Important对比线性模型

在线性模型中（§3），SGD 从 (0, 0) 出发也能收敛，因为二次损失函数的任何初始值都指向同一个碗底，而且碗是”正”的——各方向曲率相当。

非线性模型即使只有一个全局最小值，等高线的形状也可能高度不对称（椭圆而非圆），导致不同方向的收敛速度差异很大。这就是为什么在实践中，好的初始值能节省大量计算时间。

5.8.4 展望：更聪明的优化方法

上面两个实验揭示了朴素 SGD 的核心困境：学习率是全局统一的，但损失曲面在不同方向上的陡峭程度（曲率）可能差异巨大。一个学习率不可能同时适配所有方向。

现代优化算法通过自适应学习率来解决这个问题——为每个参数维护独立的、动态调整的学习率：

  • Momentum：给 SGD 加上”惯性”，在平坦方向积累速度，在震荡方向自动衰减
  • RMSProp：用梯度平方的移动平均来归一化，陡峭方向自动缩小步长
  • Adam（最常用）：结合 Momentum 和 RMSProp，同时维护梯度的一阶和二阶矩估计
Note从饱和曲线到神经网络

在我们的 2 参数饱和曲线上，手动调一下学习率就够了。但在有数百万参数的神经网络中，损失曲面的复杂程度远超想象——几百万维空间中到处是鞍点和狭窄山谷。Adam 等自适应方法几乎是标配。

从这个角度看，本文中用链式法则手推梯度的过程，与深度学习框架（PyTorch、TensorFlow）中的自动微分做的是完全相同的事——只不过自动微分把链式法则交给了计算机。

NoteSGD 不是唯一的迭代方法

对于非线性最小二乘问题，除了 SGD，还有 Gauss-Newton、Levenberg-Marquardt 等专门的优化算法（R 中 nls() 函数就用了这类方法）。但 SGD 是最通用的——当模型变得更复杂（比如神经网络有数百万参数）时，SGD 及其变种（Adam、RMSProp 等）几乎是唯一可行的选择。从这个角度看，本文的饱和曲线模型虽然简单，但它走的正是通向深度学习的同一条路。
